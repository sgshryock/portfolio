# gordonshryock.dev

Personal portfolio site for Gordon Shryock — enterprise engineering leader specializing in DevOps, platform modernization, and AI-augmented delivery.

**Live:** [gordonshryock.dev](https://gordonshryock.dev)

## Tech Stack

- **React 18** with Vite
- **CSS** with custom properties and glassmorphism design
- **GitHub Actions** for CI/CD to GitHub Pages

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview   # preview production build locally
```

## Deployment

Pushes to `main` automatically build and deploy via GitHub Actions.
